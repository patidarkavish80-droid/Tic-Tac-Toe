# Tic-Tac-Toe 🎮

A simple **Core Java console-based Tic-Tac-Toe game** for two players.

## Features

* 2 Player game
* Player X and Player O
* 3 × 3 game board
* Row and column input
* Input validation
* Position occupied validation
* Automatic player switching
* Win detection
* Draw detection

## Technologies Used

* Java
* Scanner
* 2D Character Array
* Loops
* Conditional Statements

## How to Play

1. Run the `Main.java` file.
2. Player X starts the game.
3. Enter the row number from **1 to 3**.
4. Enter the column number from **1 to 3**.
5. Players take turns placing X and O.
6. A player wins by completing a row, column, or diagonal.
7. If all positions are filled without a winner, the game is a draw.

## Board Example

```text
_ _ _
_ _ _
_ _ _
```

Players enter positions using row and column numbers.

Example:

```text
ENTER ROW : 1
ENTER COLUMN : 2
```
